# 流式识别准确率排查与整段修正

日期：2026-11-18。

## 行为调整

预编辑默认每 500ms 累计音频更新，实际仍由耗时和积压调度；这不再意味着每次更新都要结束语音段。
当前段允许从头修正，已确认的历史段保持不变。默认连续语音上限由 3 秒恢复为 8 秒，
自然停顿默认由 300ms 调整为 500ms；配置里显式设置的静音阈值仍生效。
最短语音时长加起音缓冲超过上限时，延长上限，保证当前段能通过最短时长校验。

服务在打开每个 Qwen 流后启用 `crispasr_stream_set_full_segment_decode(stream, 1)`：

- 每次预览根据当前段全部音频生成，不把早期转写猜测当作不可改写的文本前缀。
- 发现静音时暂停周期性解码。约 200ms 短停顿时使用非终结的 refresh 修正当前短语一次；
  短停顿后恢复语音仍使用同一段上下文，长停顿达到配置阈值才确认分段。
- 短停顿修正后继续静音，不再解码或向识别器追加持续静音；只保留有限间隔缓冲供恢复语音时补回。
- 段落结束或松开按键时，若修正后没有新语音就使用已有结果，不重复解码；否则完整识别当前段和尾音。
- 没有短停顿修正时，即使停在更新边界且没有剩余样本，仍做最终完整解码；C ABI 的重复 flush 保持幂等。
- 停止前不额外补算中间预览。历史段不重识别，不对整个长录音重复收尾。
- 保留固定提示 KV 和编码器依赖缓存；移除的是转写文本约束，不是固定系统提示缓存。

新模式默认关闭，其他调用者和 CLI 原有的 stock/R2T2 文本前缀配方保持不变。
R2T2 的整段模式使用完整转写预算，避免用原来只生成增量尾部的小预算截断句子；
会话设置的正数 `max_new_tokens` 仍然限制每次生成。

完整当前段推理会增加计算量；持续讲话后的最终解码也可能增加松开后的等待。
短停顿修正后的纯静音可以复用已有结果，以避免无意义的重复识别。此项优先纠正早期错字，
不能同时保证固定的 500ms 上屏延迟。8 秒硬边界仍然没有音频重叠，跨边界截词风险尚未消除。

## 同一段音频对照

构建后运行，无需麦克风、Fcitx 或联网：

```bash
./build/tests/transcription_quality_benchmark \
  --model /path/to/qwen3-asr-0.6b-q4_k.gguf \
  --wav /path/to/problem.wav \
  --language Chinese \
  --reference-file /path/to/human-transcript.txt \
  --threads 2 \
  --output /tmp/transcription-quality.json
```

输出包括：

| 变体 | 用途 |
|---|---|
| `whole_raw` | 整段文件一次识别，不润色 |
| `prefix_stream_raw` | 旧式约 3 秒分段和转写前缀约束的对照 |
| `stream_raw` | 当前 8 秒上限、当前段整段修正，不润色 |
| `stream_polished_diagnostic` | 提供 `--polish-model /path/to/chat.gguf` 后，对新流式原文做离线分块润色诊断 |

`--config` 可读取 VAD、降噪和模型设置，`--model`、`--language`、`--step-ms` 可覆盖相应项。
润色只通过显式的 `--polish-model` 启用，不因配置里的润色开关自动加载。
所有 ASR 变体使用同一份解码、可选降噪后量化到 16 kHz 单声道 PCM16 的输入。
旧前缀流对照沿用同一 VAD/静音配置，主要隔离分段上限和转写前缀策略，
不等价于对旧版可执行文件做端到端回放。

提供人工转写时，按 Unicode 码点计算 CER，先做 NFKC、大小写折叠并移除标点和空白。
未提供人工转写时，报告不生成 CER，不能用识别器自己的结果充当正确答案。
离线润色诊断按 64 字符分块、每块 5 秒取消期限，保留失败回退原文的计数；
它用于辨别润色是否改错内容，不模拟在线 ASR 优先级和结束时 1500ms 的润色等待上限。

这是不按墙钟节奏采集的质量回放。各路径复用加载后的模型，首条路径还可能支付首次构图成本，
因此 `elapsed_ms` 不能当作公平的延迟 A/B 或实际预编辑上屏延迟。
报告包含音频、模型 SHA-256、线程、语言、静音阈值、更新间隔、转写及可选 CER。

## 静音信号与短语预览

`active` 仅表示语音段尚未结束；新增 `trailingSilenceSamples` 表示实际尾部静音。
能量检测从现有逐帧状态读取，Silero 从同次推理的双阈值概率得到；没有尾部信息的其他 VAD
维持旧行为，不按未知值丢音频。短声音不足最短语音时长时，不触发短停顿识别。

`crispasr_stream_refresh()` 只支持启用整段修正的 Qwen 流，不终结识别流，允许继续 feed。
较长静音直接确认已修正结果，无需再次 flush；取消不触发识别。
批量 VAD 在下一分析周期或 STOP 才发现恢复语音时，补回暂存音频，避免漏掉短尾音。
短停顿“分词”指完整短语预览更新，模型自行决定用词和标点，不把停顿机械转换为空格。

同名 JSON 是引入短停顿优化之前的回放记录；它不证明静音跳过的推理次数和耗时收益。

## 已验证范围

- 无模型测试覆盖 stock/R2T2 的活动段全文修正、最终边界强制解码、禁用预览后一次排空、
  token 上限、8 秒分段、400ms 短停顿不分段、历史段稳定、CER 规范化和非 BMP 字符计数。
- 本机 Qwen3-ASR-0.6B Q4_K 的 C ABI 测试中，3 次累计预览后的完整最终结果与同音频的
  独立解码一致；重复 flush 没有增加推理次数。
- 现有 3.255 秒 Korean 样本 `ko-369.wav` 的三条 ASR 路径最终文字一致，见同名 JSON。
  未提供人工转写，未计算 CER。这个短样本无法证明中文准确率或长句边界质量得到改善。

中文准确率结论需要对用户实际问题录音提供人工转写后比较，不能从逻辑测试通过推导。

## 短停顿优化的补充验证

短停顿刷新后继续 feed 的真实模型 C ABI 测试通过，完整最终结果仍与独立解码一致；
结束后的 refresh 被拒绝，普通前缀模式未启用此接口时也被拒绝。
真实节奏 6 秒回放的一次测量为：松开前 6 次预览，首次约 877ms，收尾约 892ms。
日志在短停顿完成修正后没有再对同段纯静音做最终解码。
这仍是单次 Korean 夹具回放，不能据此宣称中文 CER 或普遍延迟收益。

新增无模型测试覆盖：持续静音只刷新一次、长停顿确认不重复解码、小停顿后恢复同段、
空结果撤回、短声音过滤、早于 200ms 的配置分段、取消不识别，以及批量 VAD 在 STOP
或下一分析周期才发现新语音时保留音频。
